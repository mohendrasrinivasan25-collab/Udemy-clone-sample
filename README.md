# Udemy Clone 🎓

A simple *Udemy-inspired course website* created using *HTML5 and CSS3*. This project focuses on recreating the basic layout and visual structure of an online learning platform.

The website includes a navigation bar with search, course categories, banner section, recommended courses, recommended topics, popular courses, and a footer section. Course cards display course images, titles, instructors, ratings, and pricing.

## Features

- Navigation bar with search
- Course category section
- Banner section
- Recommended courses
- Recommended topics
- Most Popular courses
- Course cards with images, ratings, and prices
- Footer section

## Technologies Used

- HTML5
- CSS3
##  Purpose

The main purpose of this project is to practice *HTML Structure, CSS Styling, Flexbox, Spacing, Alignment and Webpage layout* while building a real-world website interface.
